02 / The lifecycle of a strategy

From idea to implementation.

Work happens in our private repository. A strategy only becomes public once it has been rigorously tested and explicitly approved for publication.

01
In the private repo
Strategies and research live in the club's own repository, where drafts, dead ends and half-finished code are allowed to be exactly that.
02
Rigorous testing
A strategy is published only once it has passed our testing framework and a maintainer approves it. There is no automatic path out.
03
Copied to the public repo
The approved code and its write-up are copied to a public mirror, which this page indexes. The private research remains secure.
03 / What gets published

Strategies, tools, and falsified ideas.

A publication can be a fully-fledged trading strategy, a market simulation, a small library other members can use, or an investigation that proved a hypothesis wrong. All of them belong here.

Publishing the strategies that failed is not modesty. A signal you can rule out is a real edge, and a library that only contains successes is not describing the work honestly.
